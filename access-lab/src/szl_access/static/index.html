Known limits
    
            
    
            
    Exports hashes, state, and run metadata only, not your HTML, binding text, or model details. Review before sharing: hashes can still identify a known document. Keep the full local receipt for review.
    
          
    
        
    
        
    
          
    A person still needs to try it.
    
          
    This is a review guide, not a sign-off or an automated approval.
    
          
    1. Read the label in context. Does it describe the field correctly, without adding an unintended meaning?
    2. Try the complete task by keyboard. Check focus order, visible focus, errors, and the route to completion.
    3. Test with assistive technology. Confirm what is announced and involve people with disabilities in realistic usability testing.
    4. Check for regressions. Review the patch and run the application’s own tests before deployment.
    
          
    
          
    This first lab is limited to explicit form-label bindings. It does not establish complete WCAG conformance, legal compliance, or clinical readiness.
