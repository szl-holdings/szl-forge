# Native research front doors

The OAC System Health Lab and Foundation Confirmation keep their own scientific
layouts and service contracts. Their interfaces use a scoped projection of the
accepted KANCHAY 1.3 palette from
[`szl-brand@27d12e77fc0f9f1a0e5fae8b34adf2380d51d070`](https://github.com/szl-holdings/szl-brand/tree/27d12e77fc0f9f1a0e5fae8b34adf2380d51d070).
This does not install or imply that either service serves the full KANCHAY bundle.
The palette source is `kanchay/szl-design-system.css`, SHA-256
`da310be5cbe23dfc4054d1bb07e5b37e1a62a510e43902171e217af5c1ff0ec7`.

Both pages embed the exact `kit/logos/orbit-v2/suite/szl-icon-32.svg` from that
source, SHA-256
`6e2b7d72a3af3d9602b79de41df0194ede6496a9661f057108ec224c0efc92e6`.
The small-placement Orbit asset is credited to SZL Holdings under CC BY 4.0.
No new logo geometry, image service, font service or asset network request is
introduced. Interface code retains its Apache-2.0 license.

## Interaction and evidence

OAC keeps opaque graphite reading surfaces, visible native keyboard focus and
its explicit opt-in v2 boundary. Its self-contained page remains within the
existing inline-hash Content Security Policy. Source and workbench anchors
receive keyboard focus after the skip/navigation action.

Foundation keeps the editorial light surface and serif research hierarchy.
Its observation table and unsigned receipt are named keyboard-focusable scroll
regions. The disclosure opens with the native Space/Enter interaction. A failed
availability read clears previous ready/checkpoint labels, and GET discovery
has a ten-second deadline. Trial submission keeps the existing server contract;
the frontend adds no automatic trial retry.

Both interfaces keep all model/package digests, the registered FAILED
Foundation benchmark, synthetic-data limits, authority restrictions and
publication guards unchanged. A visual improvement is not new scientific
validation, a release signature or evidence of live publication.

## Reproduce the presentation checks

With Python Playwright and a supported Chromium installed:

```bash
python tools/verify_research_frontdoors_browser.py --output /tmp/research-frontdoor-proof
```

Set `CHROME_PATH` to a local Chromium executable when required. The harness
serves the exact source HTML/CSS/JavaScript on loopback, provides explicitly
unavailable read-only API fixtures, and refuses attempted writes and external
requests. It inspects both interfaces at 320, 390, 768, 1280 and 1920 pixels,
including skip focus, control sizes, horizontal containment and forced colors.
The Foundation table/receipt stress state is explicitly a local layout fixture;
it does not run inference or manufacture a scientific result.

The existing OAC suite and Foundation runtime/release gates continue to verify
their own artifact and service contracts. Hosted publication still goes through
`oac-health-space.yml` and `foundation-runtime.yml` on the accepted source,
followed by their existing immutable Hub and runtime checks.
