## 9. Origin binding text and merge practice
4. **Origin binding (v3 `verify_origin`).** For a receipt naming commit C, all of these must hold:
   - (a) C is reachable from a public `oac-v3-*` tag.
   - (b) At C, the kernel, generator, manifest, preregistration and amendments blobs match the
     receipt's digests (v2's rule).
   - (c) At C, the trace that the receipt binds (the fit trace, or a retrain's trace) and the
     receipts directory match the receipt's digests.
   - (d) At C's first parent, that trace is absent or different.

   (c) and (d) together make C the unique commit that introduced the trace. Re-pointing to a
   parent or to a descendant therefore fails. That is the v2 blind spot `R-source-commit-other`
   (MEASURED: `v2/results/MUTATION_READINESS.md`).
5. **Publicly verifiable origin, unlike v2.** A fresh clone of the public tag must run every
   origin test with 0 skipped. A skip counts as a failure, not as UNAVAILABLE. For contrast, v2
   skips 7 origin tests in szl-forge (MEASURED: `REPORT.md` §7.2 caveat 1).
6. **Merge safety.** Tags keep the receipt commits reachable even if a later squash merge leaves
   the branch history out of `main`. The branch is not deleted while a tag depends on it. Tag
   protection for `oac-v3-*` is a repository setting, and Stephen decides on it.
