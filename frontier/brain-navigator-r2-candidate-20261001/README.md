## Binding the curriculum

`candidate.json` -> `training_data`. `binding_status` is `UNBOUND` until eligible files are bound with SHA-256 digests.
The earlier heuristic Brain corpus selection was rejected because its recorded local path is missing and Brain rows are excluded from gradients by this candidate's rights boundary.
Admitted rows must be project-authored or rights-documented; dev/test rows, Brain rows, OSINT rows and
other-model outputs never enter gradients. Accepted record shapes: `messages`, `prompt`/`completion`,
`instruction`(+`input`)/`output`, `input`/`output`, `text`/`label`; an optional `split` field
(`train|dev|test|adversarial|quarantine`) and `family_key` are honoured.

## Changing a threshold

`gates.json` is frozen by hash in `candidate.json` (`gates_sha256`). To change a threshold before any result exists,
edit `gates.json` and re-pin the hash in the same commit; `candidate_lib.load_gates` refuses a mismatch. Template-leak
overlap is reported (WARN) and blocks only when `leakage.template_leak_blocks` is true.
